# 🎄 숲별 트리 설계

연말 콘서트를 기다리며 숲별들이 같이 트리를 키우고, 오너먼트에 글을 걸어 두는 기능.
서버·로그인 없이 지금 사이트 방식(구글 폼 줄 + 시트 CSV)을 그대로 씀.

---

## 1. 화면

**주소** `#/tree` · 더보기 '숲별 소통' 칸 + 홈 칸(홈 화면 편집으로 끌 수 있음)

**위에서부터**
1. 제목 줄: `🎄 숲별 트리 · Lv5 트리` · `💧 128 / 150 · 다음: 전구`
2. 3D 트리 (화면 높이의 65%쯤)
   - 한 손가락 좌우로 밀기 = 트리 돌리기
   - 오너먼트 누르기 = 작은 카드(닉네임 · 받는 사람 · 건 날짜 · 🔒)
3. 바구니 줄 (자리 꽉 찼을 때만): `🧺 3개가 기다려요 · 물 12개 더 주면 다 걸려요`
4. 버튼 두 개: `💧 물 주기` · `🎁 오너먼트 달기`
5. 작은 글씨: `오너먼트 편지는 연말 콘서트 날 0시에 한 번에 열려요`

**홈 칸** 작은 트리 그림(정지 사진) + `💧 오늘 물 주기` 버튼 하나. 누르면 바로 물 주기, 트리 화면은 한 번 더 눌러야 열림.

---

## 2. 3D 트리

- three.js는 트리 화면에 들어갈 때만 불러옴(다른 화면은 안 느려짐). `lib/three.module.min.js` (670KB, 한 번 받으면 폰에 저장)
- 트리 모델: `tree.glb` (Tripo 단순 트리, 406KB) → 코드로 색칠 + 모양 다듬기(줄기 짧게, 가지 넓게, 층 끝 물결)
- 장식(사이트가 다는 것): 구슬 · 양말 · 작은 별 · 꼭대기 별 · 선물 상자. 모두 각진 로우폴리, 줄 장식·빛 번짐 없음
- 양말은 트리 겉면 기울기에 맞춰 붙임(지금 시안의 90도 → 수정)
- 하늘은 폰 시간 따라 4가지(새벽·낮·노을·밤), 밤엔 별
- 폰이 3D를 못 돌리면 정지 사진 + 버튼만 보여줌

### 레벨 (목록 한 줄 = 한 레벨, 나중에 줄만 추가)

| Lv | 이름 | 물(누적) | 오너먼트 자리 | 모습 |
|---|---|---|---|---|
| 1 | 씨앗 | 0 | 0 | 흙 + 씨앗 |
| 2 | 새싹 | 10 | 0 | 잎 두 장 |
| 3 | 아기 나무 | 30 | 10 | 작은 트리 |
| 4 | 작은 나무 | 60 | 25 | 허리 높이 |
| 5 | 트리 | 100 | 50 | 다 자란 키 |
| 6 | 구슬 | 150 | 80 | 사이트 구슬 장식 |
| 7 | 양말·선물 | 220 | 120 | 양말 + 바닥 선물 |
| 8 | 눈 | 300 | 160 | 눈 덮임 |
| 9 | 별 | 400 | 200 | 꼭대기 별 |

- 레벨마다 뒤쪽 숲(작은 나무)이 늘어남, 하늘 별 수 = 물 준 숲별 수
- 레벨이 오른 순간 처음 들어온 사람에게 `🎉 트리가 Lv6이 됐어요!` 한 번

## 3. 물 주기

- 폰마다 하루 1번 (서울 날짜 기준, 브라우저 번호 sb-uid)
- 누르면 폼 줄 `종류: 물 / 누가: uid` 보내고, 화면에 물방울 + 트리 살짝 흔들림
- data.js가 사람·날짜별 첫 줄만 셈 → 누적 물 수, 물 준 사람 수
- 폰 기록 `sb-tree` { water: [날짜...], mine: [오너먼트 id...] }

## 4. 오너먼트 달기

- 그날 물을 줬으면 열림 (하루 1개)
- 고르기: 모양(구슬 · 양말 · 별) × 색(8가지), 받는 사람(포레에게 / 숲별에게), 닉네임(비우면 '익명의 숲별'), 글 200자
- 달기: 트리를 톡 누르면 그 자리에 붙음 → 한 손가락으로 겉면 따라 이동, 두 손가락으로 크기(0.7~1.5배)·회전 → `여기 달기`
  - 다는 동안 트리 안 돌아감, 다른 오너먼트랑 겹치면 살짝 밀어냄
- 폼 줄 `종류: 오너먼트 / 누가 / 모양 / 색 / 받는이 / 닉네임 / 자리: 각도,높이,크기,회전 / 내용: SEC1:암호글`
- 자리가 꽉 찼으면 🧺 바구니에 들어가고, 트리가 자라면 먼저 온 순서대로 자동으로 걸림 (그때 자리는 비어 있는 곳 중 가까운 곳)

## 5. 잠금 · 열기

- 글은 보내기 전 폰에서 암호화 (비밀글 SEC1과 같은 방식, '트리 열쇠' 공개키는 config.js)
- 트리 열쇠 비밀 쪽은 관리자 폰에만 → 수정 님은 미리 읽고 숨길 수 있음
- 열리는 날: config.js `treeOpen` (연말 콘서트 날 0시). 그날 비밀 열쇠를 config.js에 넣어 배포 → 모든 폰에서 열림
- 내가 쓴 건 내 폰에서 미리 읽을 수 있음
- 연 뒤: 오너먼트 누르면 글 전체, 위에 `📜 전체 편지 보기` 목록(포레에게 / 숲별에게 칩)

## 6. 관리

- 내 오너먼트 지우기 (가사삭제와 같은 방식)
- ⋯ 신고 · 숨김 요청 (지금 있는 것)
- 관리자: 미리 읽기, 숨기기(서명 줄), 열쇠 넣기 전 '열림 미리보기'

## 7. 숫자 · 날짜 (정해야 할 것)

- 시작일: 11월 ○일
- 연말 콘서트 날짜 → `treeOpen`
- 시트 줄 수: 물 하루 수십 줄 → 하트 줄 정리처럼 Apps Script로 매일 합치기(나중에)

## 8. 만드는 순서 (토큰 아끼기)

1. 트리 화면 + 레벨 + 물 주기 (오너먼트는 사이트 장식만)
2. 오너먼트 달기 + 잠금 + 바구니
3. 열기 · 편지 목록 · 관리
4. 홈 칸 · 새 소식 줄(수정 님 OK 받고) · 영어/일본어

각 단계 끝에 캡처 1~2장만.
